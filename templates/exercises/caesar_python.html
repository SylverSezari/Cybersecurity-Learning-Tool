Eine römische Botschaft verschlüsseln

Ein römischer Bote soll eine Nachricht durchs feindliche Gebiet bringen. Du hilfst ihm, jeden Buchstaben mit Python drei Stellen weiterzuschieben.

Bevor du startest

Was macht der Code?

Der Computer liest die Anweisungen von oben nach unten. Die Zeile text = "HALLO" speichert die Nachricht. key = 3 legt fest, dass jeder Buchstabe um drei Plätze verschoben wird. alphabet ist eine Reihe mit allen Buchstaben, und encrypted sammelt die verschlüsselte Nachricht.

Die Schleife for letter in text bearbeitet die Nachricht Buchstabe für Buchstabe. Mit alphabet.index(letter) findest du die Nummer eines Buchstabens: A hat Nummer 0, B hat Nummer 1 und so weiter. Addiere dann den Schlüssel 3. Weil das Alphabet nur 26 Buchstaben hat, sorgt % 26 dafür, dass es nach Z wieder bei A weitergeht. Zum Schluss fügt der Code den neuen Buchstaben an encrypted an.

Beispiel: H steht an Stelle 7. Mit dem Schlüssel 3 wird daraus Stelle 10, also K. Wenn alle Buchstaben verarbeitet sind, gibt print(encrypted) das Ergebnis aus.

Auftrag des römischen Boten

Verschlüssle die Nachricht

Im römischen Lager muss ein Bote die Nachricht HALLO an seine Verbündeten schicken, ohne dass der Feind sie sofort lesen kann. Der Hauptmann gibt ihm den Schlüssel 3: Jeder Buchstabe soll drei Plätze im Alphabet vorrücken.

Der Code ist fast fertig. Ergänze die beiden TODO-Zeilen: Finde zuerst die Nummer des aktuellen Buchstabens. Berechne danach seine neue Nummer, indem du den Schlüssel addierst und mit % 26 im Alphabet bleibst.

  1. alphabet.index(letter) liefert die Stelle des Buchstabens, zum Beispiel 0 für A.
  2. Die neue Stelle ist die alte Stelle plus key, gerechnet mit % 26.

Ändere nur die beiden Zeilen mit 0. Du kannst den Code jederzeit zurücksetzen und erneut starten.
